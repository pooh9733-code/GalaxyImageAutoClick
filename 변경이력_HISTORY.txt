갤럭시 이미지 자동클릭 — 변경 이력

v1.0 (2026-11-12)
- Windows PC 자동클릭 v8.1의 사용 목적을 Android 환경으로 재구현.
- Android 11+ 접근성 스크린샷과 터치 제스처 사용.
- 다중 이미지 등록 / 순서 이동 / 삭제 / 이미지별 클릭 횟수 및 간격.
- 이미지 중앙 영역 무작위 터치 / 대기 시간 / 건너뛰기 / 전체 반복.
- 이미지 인식 실패 기록 / 경고 상태 (미니 상태창에서 확인).
- 상단 작은 상태창과 중지 버튼 / 앱 내 실시간 로그.
- GitHub Actions를 이용한 APK 클라우드 빌드.
- PC의 듀얼 모니터, Windows 탐색기 파일 실행, 독립 백그라운드 클릭은 Android에 해당하지 않아 제외.

검증 상태: 소스 정적 점검 수행. Android 실제 기기 빌드 및 실사용 검증은 아직 미완료.
