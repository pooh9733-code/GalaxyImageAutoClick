갤럭시 이미지 자동클릭 - Android Studio 소스 프로젝트

준비물: Windows PC, Android Studio, USB 케이블, Android 11 이상 갤럭시
1. 압축 해제 후 Android Studio > Open > GalaxyImageAutoClick 폴더 선택
2. Gradle Sync 진행. Gradle JDK는 17을 사용하세요. (프로젝트에 Gradle Wrapper는 포함되지 않습니다. Android Studio가 Gradle 설치를 요구하면 로컬 Gradle 8.9를 설정하거나 wrapper를 생성하세요.)
3. 휴대폰 설정 > 휴대전화 정보 > 소프트웨어 정보 > 빌드번호 7회 터치 > 개발자 옵션 > USB 디버깅 켜기
4. USB로 연결, 디버깅 허용 > Android Studio 상단 Run 실행
5. 앱에서 이미지 선택(화면 캡처에서 클릭할 버튼을 정확히 잘라낸 이미지) > 접근성 서비스 설정에서 이미지 자동클릭 켜기 > 간격 설정 > 시작
6. 다른 앱으로 이동. 중지하려면 자동클릭 앱으로 돌아와 정지 버튼 클릭.

중요: 앱 자체가 설치 가능한 APK가 아니라 소스 코드입니다. Android Studio에서 빌드해야 합니다.
이 버전은 기본 픽셀 유사도 비교이므로 버튼 크기, 화면 배율, 애니메이션이 바뀌면 못 찾을 수 있습니다.
스크린샷 및 템플릿은 서버로 전송하지 않습니다. Android 11 이상만 지원합니다.
앱을 사용자가 직접 실행해야 하며 백그라운드/절전 상태에서 지속 실행은 보장하지 않습니다.
다른 앱의 서비스 약관을 준수하세요. 결제/인증/금융 업무 자동화에 사용하지 마세요.
