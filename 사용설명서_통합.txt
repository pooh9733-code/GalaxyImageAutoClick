갤럭시 이미지 자동클릭 v1.0 — 통합 사용설명서

[중요] 이 ZIP 파일은 APK 자체가 아닌 APK 빌드용 Android Studio 소스 프로젝트입니다.
Android 11(API 30) 이상 갤럭시에서 사용합니다. Android 10 이하에서는 실행 불가합니다.

1. GitHub로 APK 만들기 (PC 없이)
  ① github.com에서 새 저장소 생성 (예: GalaxyImageAutoClick).
  ② ZIP 압축을 풀고 내용물 전체를 저장소 최상위에 업로드. .github/workflows/build-apk.yml 포함 필수.
  ③ 저장소 Actions 탭에서 Build Android APK → Run workflow 선택.
  ④ 빌드가 성공하면 해당 Actions 실행 결과의 Artifacts에서 GalaxyImageAutoClick-debug-apk 다운로드.
  ⑤ ZIP Artifacts 압축을 풀고 app-debug.apk를 갤럭시에 설치.
  ※ Android 기기에서 직접 빌드하는 것은 아닙니다. GitHub의 빌드 서버를 사용합니다.
  ※ 스마트폰에서 .github 숨김 폴더 업로드가 어려우면 GitHub 웹의 Create new file에서
     .github/workflows/build-apk.yml 경로로 파일을 만들어 내용을 붙여넣으세요.

2. 앱 최초 설정
  ① 앱 실행 → 접근성 서비스 설정 열기.
  ② 설치된 서비스 목록에서 '이미지 자동클릭' 켜기 (접근성 경고를 확인 후 허용).
  ③ 앱으로 돌아와 + 이미지 추가 버튼 → 파일 선택.
  ④ 이미지를 2개 이상 넣으면 위아래 화살표로 실행 순서 조절.
  ⑤ 횟수 버튼에서 이미지별 클릭 횟수와 간격 설정.
  ⑥ 미인식 알림, 건너뛰기, 작은 실행 상태창 설정 후 '설정 저장'.
  ⑦ '자동클릭 시작' → 다른 앱을 열어 화면에 이미지가 보이도록 함.
  ⑧ 작은 상태창의 '중지' 버튼 또는 앱으로 돌아와 '중지' 선택.

3. 클릭 규칙
  - 1번 이미지를 화면에서 찾음 → 지정 횟수만큼 터치 → 2번 이미지 검색.
  - 이미지별 중앙 ±15%(초깃값) 범위에서 터치마다 랜덤 좌표 선택.
  - 찾기 제한 시간 초과 시 '경고 상태 표시' 옵션 ON이면 화면 상태/기록에 경고 표시.
    이 경고는 별도 강제 팝업이 아닌 미니 상태창 경고/앱 기록입니다.
  - 건너뛰기 ON이면 다음 단계로, OFF면 자동 중지.
  - 0회 반복은 무한 반복이고, 이미지 클릭 횟수 1~100회 설정 가능.

4. Windows 버전과 다른 점
  - Windows EXE/BAT/Excel 파일을 갤럭시에서 직접 실행할 수 없습니다.
  - Android는 실제 화면 터치이므로 '특정 창 백그라운드 클릭+손가락 독립'을 보장하지 않습니다.
  - 갤럭시 기본 화면에 표시되는 앱만 검색하며 보안 처리된 화면은 캡처되지 않습니다.
  - 이미지 비교는 유사 픽셀 방식이며 크기 변경, 화면 배율 변경에 약합니다.
  - 갤럭시 화면에 표시되는 크기대로 캡처한 버튼 이미지를 등록하세요.
  - 터치와 동시에 손가락을 사용하면 터치가 취소될 수 있습니다.
  - 앱과 타 앱 간 화면 전환을 막는 앱에서는 자동화가 작동하지 않을 수 있습니다.

5. 문제 해결
  - 시작 안 됨: 설정 → 접근성 → 설치된 앱 → 이미지 자동클릭 서비스 켜기.
  - 못 찾음: 정확히 해당 버튼만 작은 영역으로 캡처, 표시 크기와 비율 확인.
  - 일부 앱 불가: 보안 창 / 앱의 스크린샷 제한 / 터치 차단 여부 확인.
  - GitHub 빌드 실패: Actions 로그에서 실패 단계 확인 후 화면 캡처 공유.
  - 클릭을 멈추려면 상태창의 '중지' 또는 앱의 '중지' 클릭.

6. 개인정보
  - 이미지 파일은 앱의 내부 저장소에 저장됩니다.
  - 네트워크 통신 권한을 요청하지 않으며, 화면 이미지를 외부 서버에 전송하지 않습니다.
  - 사용자가 직접 접근성 서비스를 활성화해야 합니다.
